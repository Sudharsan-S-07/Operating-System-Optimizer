# Operating System Optimizer

Operating System Optimizer is a system monitoring and optimization tool.

## Features
- Memory monitoring
- Disk scheduling optimization
- CPU resource monitoring
- Power efficiency monitoring
- Real-time system metrics visualization

## Technologies
- C (system daemon)
- Python Tkinter GUI
- Matplotlib
- Linux system calls

## Run Backend

gcc backend/backend.c -o optimizer
./optimizer

## Run Frontend

python frontend/frontend.py
